# PHP Switcher for XAMPP

A Windows desktop application for managing and switching
between multiple PHP versions in XAMPP.

## Features

- Switch PHP versions with one click
- Detect the currently installed PHP version
- Automatic XAMPP detection
- Backup existing PHP installation before switching
- Preserve PHP configuration
- Support multiple PHP 8.x versions
- Validate PHP after switching
- Modern Windows desktop interface
